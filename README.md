Finance Risk & Loan Portfolio Analytics

An interactive Power BI dashboard for analyzing loan portfolio performance, financial risk, defaults, NPA exposure, recovery, and customer/loan trends.

Project Overview

This project uses Power BI, DAX, and Power Query to transform financial loan data into an interactive business intelligence dashboard.

The dashboard helps analyze:

Loan portfolio performance
Loan defaults and bad loans
NPA exposure
Recovery performance
Loan growth and trends
Customer risk segments
Regional performance
Loan-type performance
Key financial KPIs
